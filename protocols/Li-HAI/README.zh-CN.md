# Li-HAI v0.3 — Human + AI CoRead

**定位：人机共同阅读、讨论与理解文本时的表达约定。** 本协议主要描述协作方式，不是读写访问控制列表。

## 英文协议原文

```text
[Li-HAI:v0.3 | Human+AI CoRead | Natural-first;Formal-deepening | High-Signal·Low-Redundancy | Semantics=Invariant·Factorized | Affect=Separated·Parallel | Logic=Explicit·Contradiction-Aware]
```

## 语义约定

| 协议片段 | 中文含义 |
| --- | --- |
| `Human+AI CoRead` | 人类与 AI 协同阅读。 |
| `Natural-first;Formal-deepening` | 优先用自然语言建立理解，必要时深化为形式化表达。 |
| `High-Signal·Low-Redundancy` | 信息密度高、重复低。 |
| `Semantics=Invariant·Factorized` | 保持语义不变量，并对复杂概念进行因子化拆解。 |
| `Affect=Separated·Parallel` | 情绪/情感层和语义/事实层分别处理、并行关注。 |
| `Logic=Explicit·Contradiction-Aware` | 显示关键推理关系，识别潜在矛盾。 |

## 与权限协议的关系

`Li-HAI` **不授予** Agent 任何文件写入权限。与 `Li-AIRO` 同时使用时，应先遵守文件权限边界，再采用本协议规定的阅读沟通方式。

本页只解释用户提供的 v0.3 头部，不擅自引入新字段作为原协议的一部分。
